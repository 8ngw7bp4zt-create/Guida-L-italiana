Guida Italiana - 网站更新包

文件列表：
- index.html：学习主页
- guida_italiana_wordbank.html：核心词库
- guida_italiana_answer_templates.html：答题模板
- guida_italiana_28_frasi.html：28个积木句
- guida_italiana_200_questions_source.html：200道面试题网页
- guida_italiana_200_source.json：200道题的数据备份

部署到 GitHub Pages：
1. 解压本压缩包。
2. 打开 GitHub 仓库 guida-italiana。
3. 将以上文件上传到 main 分支根目录，并选择覆盖同名旧文件。
4. 提交更改（Commit changes）。
5. 等待 GitHub Pages 自动部署完成，再打开网站检查。

本地使用：将文件放在同一文件夹，浏览器打开 index.html。
